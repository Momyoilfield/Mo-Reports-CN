# Mo 全球石油产业报告（中文版）

Mo 刊物体系的公开出版物（中文版）：事实与一般市场分析。Mo 自身经营内容见内部《Mo内参》，不在此公开。

英文版见 [Mo-Reports-EN](https://github.com/Momyoilfield/Mo-Reports-EN)。

## 月报 — 《Mo全球石油产业月报》

每月最后一个日历日 08:00（北京时间）发布。上半部为上游产业全景，下半部为下游宏观分析。

- `monthly/2026-10-30/` — 创刊号（中文 Word + PDF）

## 周报 — 《Mo石油产业周报》

每周日 20:00（北京时间）发布：产量与钻机变化、价格走势、OPEC 动态、本周大事、展望。首期 2026年11月15日。

## 来源与口径

每期附录列明数据来源与口径。同一件事不同机构数字不同，是口径不同，不是谁算错了；查不到的数字直接写「无公开数据」，不估、不编。
